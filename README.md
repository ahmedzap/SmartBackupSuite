## 📋 نظرة عامة

**Smart Backup Suite** هو تطبيق سطح مكتب متكامل مصمم لإدارة عمليات النسخ الاحتياطي لقواعد بيانات SQL Server بسهولة وكفاءة. يوفر التطبيق واجهة مستخدم عصرية وسهلة الاستخدام، مع دعم متعدد للوجهات السحابية وجدولة مرنة.

### ✨ المميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| 🗄️ **نسخ احتياطي لـ SQL Server** | دعم Full, Differential, Log Backup |
| ☁️ **وجهات سحابية متعددة** | Google Drive, Dropbox, OneDrive, AWS S3, Azure Blob |
| ⏰ **جدولة مرنة** | يومي، أسبوعي، شهري، فترة زمنية، مخصص |
| 🔐 **أمان متقدم** | تشفير الملفات، ضغط، سياسة احتفاظ |
| 📊 **لوحة تحكم** | إحصائيات ومخططات بيانية متقدمة |
| 📧 **إشعارات البريد الإلكتروني** | إشعارات بنجاح أو فشل العمليات |
| 🖥️ **واجهة عربية** | دعم كامل للغة العربية |

## 🔧 التثبيت والتشغيل

### 1. استنساخ المشروع

```bash
git clone https://github.com/yourusername/SmartBackupSuite.git
cd SmartBackupSuite
```

### 2. تثبيت المكتبات

```bash
dotnet restore
```

### 3. تشغيل التطبيق

```bash
dotnet run --project SmartBackupSuite.csproj

dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

## 📖 دليل الاستخدام الكامل

### 1️⃣ إعداد الاتصال بقاعدة البيانات

قبل إنشاء أي مهمة، يجب إعداد اتصال بقاعدة البيانات:

1. **افتح الإعدادات**: انقر على زر `⚙️ الإعدادات` في النافذة الرئيسية
2. **إضافة اتصال**: في قسم `🔌 اتصالات SQL Server`، انقر على `➕ إضافة`
3. **أدخل بيانات الاتصال**:
   - **اسم الاتصال**: اسم تعريفي (مثل: "خادم الإنتاج")
   - **اسم الخادم**: اسم أو IP خادم SQL Server (مثل: `localhost` أو `192.168.1.100`)
   - **نوع المصادقة**: اختر `Windows` أو `SQL`
   - **اسم المستخدم**: إذا اخترت `SQL`، أدخل اسم المستخدم (مثل: `sa`)
   - **كلمة المرور**: أدخل كلمة المرور
4. **حفظ**: انقر على `حفظ`

> 💡 **نصيحة**: اختبر الاتصال عن طريق تحميل قواعد البيانات في خطوة إنشاء المهمة.

---

### 2️⃣ إنشاء مهمة نسخ احتياطي جديدة

#### الخطوة 1: المعلومات الأساسية

1. في النافذة الرئيسية، انقر على `➕ إضافة مهمة`
2. أدخل البيانات التالية:
   - **اسم المهمة**: اسم تعريفي (مثل: "نسخ يومي لقاعدة العملاء")
   - **الاتصال**: اختر الاتصال الذي قمت بإعداده سابقاً
   - **نوع النسخ**: اختر من (`Full`، `Differential`، `Log`)
   - **عدد النسخ المحتفظ بها**: عدد النسخ الاحتياطية المحفوظة محلياً
3. اختر الخيارات الإضافية:
   - ☑️ **ضغط النسخة**: لتقليل حجم الملف
   - ☑️ **تشفير النسخة**: لحماية البيانات
   - ☑️ **المهمة نشطة**: لتفعيل الجدولة التلقائية
   - ☑️ **تنفيذ المهام الفائتة**: لتنفيذ المهام التي فات وقتها
   - ☑️ **الاحتفاظ بنسخة محلية**: للاحتفاظ بنسخة على الجهاز

#### الخطوة 2: اختيار قواعد البيانات

1. انقر على `🔄 تحميل القواعد` لجلب قائمة قواعد البيانات من الخادم
2. حدد قواعد البيانات المراد نسخها عن طريق وضع علامة ✅ بجانب كل قاعدة
3. استخدم `☑️ تحديد الكل` أو `⬜ إلغاء التحديد` للتحكم السريع
4. استخدم حقل `🔍 بحث في قواعد البيانات...` للبحث عن قاعدة معينة

#### الخطوة 3: تحديد الجدولة

اختر نوع الجدولة المناسب:

| نوع الجدولة | الوصف |
|-------------|-------|
| **مرة واحدة** | يتم التنفيذ في وقت محدد لمرة واحدة فقط |
| **يومي** | يتم التنفيذ يومياً في الوقت المحدد |
| **أسبوعي** | يتم التنفيذ في يوم محدد من الأسبوع |
| **شهري** | يتم التنفيذ في يوم محدد من الشهر |
| **فترة زمنية** | يتم التنفيذ كل X دقيقة |
| **مخصص** | جدولة متقدمة بأيام وأوقات مختلفة لكل يوم |

**خيارات إضافية:**
- **وقت البدء**: الوقت الذي تبدأ فيه الجدولة
- **تنفيذ المهام الفائتة**: تنفيذ المهام التي فات وقتها عند تشغيل الجهاز
- **الحد الأقصى للفوات**: الحد الأقصى لعدد مرات الفوات

#### الخطوة 4: اختيار وجهة الحفظ

اختر مكان حفظ النسخ الاحتياطي:

| الوجهة | الوصف |
|--------|-------|
| **محلي** | حفظ على مجلد محلي في الجهاز |
| **شبكي** | حفظ على مسار شبكة مشترك |
| **Google Drive** | رفع تلقائي إلى Google Drive |
| **Dropbox** | رفع تلقائي إلى Dropbox |
| **OneDrive** | رفع تلقائي إلى OneDrive |
| **AWS S3** | رفع إلى Amazon S3 |
| **Azure Blob** | رفع إلى Azure Blob Storage |

**🔐 إعداد الوجهات السحابية:**

##### Google Drive
1. أنشئ ملف `credentials.json` من [Google Cloud Console](https://console.cloud.google.com/)
2. ضع الملف في مجلد التطبيق
3. ستفتح نافذة المتصفح للمصادقة تلقائياً

##### Dropbox
1. يتم المصادقة تلقائياً باستخدام `App Key` المدمج
2. ستفتح نافذة المتصفح لتسجيل الدخول

##### OneDrive
1. سجل تطبيق في [Azure Portal](https://portal.azure.com)
2. حدّث `ONEDRIVE_CLIENT_ID` في الكود

### 3️⃣ إدارة المهام

#### عرض المهام
- تظهر جميع المهام في الجدول الرئيسي
- يمكنك رؤية حالة كل مهمة (نشطة/غير نشطة)
- عرض آخر وقت تنفيذ ونتيجته

#### تنفيذ مهمة يدوياً
1. في الجدول الرئيسي، ابحث عن المهمة المطلوبة
2. انقر على زر `▶️ تنفيذ` بجانب المهمة
3. سيتم تنفيذ المهمة فوراً

#### تعديل مهمة
1. حدد المهمة من الجدول
2. انقر على `✏️ تعديل مهمة`
3. قم بتعديل البيانات المطلوبة
4. احفظ التغييرات

#### حذف مهمة
1. حدد المهمة من الجدول
2. انقر على `🗑️ حذف مهمة`
3. أكد الحذف

### 4️⃣ لوحة التحكم

لعرض لوحة التحكم، انقر على `📊 لوحة التحكم` في النافذة الرئيسية.

#### البطاقات الإحصائية

| البطاقة | الوصف |
|---------|-------|
| **📋 إجمالي المهام** | عدد المهام الكلي والنشطة |
| **✅ نسبة النجاح** | النسبة المئوية للمهام الناجحة |
| **❌ مهام فاشلة** | عدد المهام الفاشلة |
| **⏱️ متوسط الوقت** | متوسط وقت تنفيذ المهام |
| **💾 إجمالي الحجم** | إجمالي حجم الملفات المحفوظة |

#### المخططات البيانية

| المخطط | الوصف |
|--------|-------|
| **📊 حالة المهام** | مخطط دائري يوضح نسبة النجاح والفشل |
| **📈 أداء المهام** | مخطط شريطي لأداء المهام في آخر 7 أيام |
| **📈 اتجاه النسخ الاحتياطي** | مخطط خطي لآخر 20 عملية |
| **📊 أداء كل مهمة** | مخطط عمودي لكل مهمة |

#### تصفية البيانات

- **📊 الحالة**: تصفية حسب نجاح/فشل/قيد الانتظار
- **🔍 بحث**: البحث عن مهمة معينة
- **📅 من/إلى**: تصفية حسب الفترة الزمنية

---

### 5️⃣ عرض السجلات

#### عرض السجلات من التطبيق
1. انقر على `📋 السجلات` في النافذة الرئيسية
2. ستظهر نافذة تعرض جميع السجلات
3. يمكنك تصفية السجلات حسب:
   - الفترة الزمنية (من/إلى)
   - الحالة (نجاح/فشل/تحذير)
   - البحث النصي

#### موقع ملفات السجلات
```
%AppData%\SmartBackupSuite\Logs\
```

### 6️⃣ إعدادات البريد الإلكتروني

#### تفعيل الإشعارات
1. اذهب إلى `⚙️ الإعدادات`
2. في قسم `📧 إشعارات البريد الإلكتروني`
3. فعّل `تفعيل الإشعارات`
4. أدخل البيانات التالية:

| الحقل | القيمة |
|-------|--------|
| **البريد الإلكتروني** | البريد المستلم للإشعارات |
| **خادم SMTP** | `smtp.gmail.com` (لـ Gmail) |
| **المنفذ** | `587` |
| **اسم المستخدم** | بريدك الإلكتروني الكامل |
| **كلمة المرور** | كلمة مرور التطبيق |

#### الحصول على كلمة مرور التطبيق (Gmail)

1. اذهب إلى [Google App Passwords](https://myaccount.google.com/apppasswords)
2. فعّل المصادقة بخطوتين
3. أنشئ كلمة مرور تطبيق جديدة
4. اختر "بريد إلكتروني" و "Windows"
5. انسخ كلمة المرور واستخدمها

> ⚠️ **ملاحظة هامة**: لا تستخدم كلمة المرور العادية لحساب Gmail. استخدم كلمة مرور التطبيق (App Password) فقط.

### 7️⃣ سياسة الاحتفاظ السحابي

#### إعداد سياسة الاحتفاظ
1. في خطوة اختيار الوجهة، اختر وجهة سحابية
2. انقر على `☁️ إعدادات الاحتفاظ`
3. حدد الإعدادات التالية:

| الإعداد | الوصف |
|---------|-------|
| **عدد أيام الاحتفاظ** | عدد الأيام للاحتفاظ بالملفات |
| **الحد الأقصى للنسخ** | أقصى عدد من النسخ المحتفظ بها |
| **الحد الأقصى للحجم** | الحد الأقصى لحجم الملفات (GB) |
| **ضغط الملفات** | ضغط الملفات قبل الرفع |
| **تشفير الملفات** | تشفير الملفات قبل الرفع |
| **الاحتفاظ بنسخة سنوية** | الاحتفاظ بنسخة واحدة لكل سنة |
| **عدد سنوات الاحتفاظ** | عدد السنوات للاحتفاظ بالنسخ السنوية |

#### تنظيف يدوي
- انقر على `🧹 تنظيف الآن` لحذف الملفات القديمة فوراً

## 🛠️ استكشاف الأخطاء وإصلاحها

### ❌ خطأ في الاتصال بقاعدة البيانات

```
تأكد من:
- صحة بيانات الاتصال
- أن الخادم يعمل
- أن لديك صلاحيات الوصول
- أن SQL Server Browser يعمل
- أن جدار الحماية يسمح بالاتصال
```

### ❌ فشل الرفع إلى Google Drive

```
تأكد من:
- وجود ملف credentials.json في مجلد التطبيق
- صحة بيانات المصادقة
- اتصال الإنترنت
- أن لديك مساحة كافية في Google Drive
```

### ❌ فشل إرسال البريد الإلكتروني

```
تأكد من:
- صحة خادم SMTP والمنفذ
- استخدام كلمة مرور التطبيق (وليس كلمة المرور العادية)
- تفعيل المصادقة بخطوتين في Gmail
- اتصال الإنترنت
- أن البريد الإلكتروني المستلم صحيح
```

### ❌ فشل الرفع إلى السحابة

```
تأكد من:
- صحة بيانات المصادقة
- اتصال الإنترنت
- أن لديك صلاحيات الكتابة في الوجهة
- أن حجم الملف لا يتجاوز الحد المسموح
```

### ❌ عدم ظهور أيقونة علبة النظام

```
- تأكد من أن التطبيق يعمل في الخلفية
- تحقق من إعدادات Windows Taskbar
- أعد تشغيل التطبيق
```

### ❌ خطأ في سياسة الاحتفاظ

```
تأكد من:
- أن سياسة الاحتفاظ مفعلة
- أن الحد الأقصى للنسخ أكبر من صفر
- أن عدد أيام الاحتفاظ موجب
```
